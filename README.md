## Repositorios usados de ejemplo

https://github.com/decached/2pc este repo de uso para entender y ayudarnos a definir la estructura modular del sistema (coordinador, servidor y transacción). Sirvió para definir cómo manejar los estados de transacción (ABIERTA, EN_PREPARACIÓN, CONFIRMADA, ABORTADA, INVÁLIDA) mediante una clase encargada


## Herramientas de codigo generativo

Ademas de el repositorio, que fue una guia de como estrucutrar el problema, se utilizo herramientas como copilot incorporado en vscode, chatgpt y gemini, para corregir bug de error del programa, asi como tambien para crear mas test que evaluaran casos borde. 
Ademas se utilizo para corregir y desarrollar el archivo Simulator

Tambien se utilizo para juntar las dos partes hechas por los dos estudiantes. Uno se encargo del motor de transacciones y el otro se encargo de los que era, leer, escribir y validar los outputs y resultados para la db
